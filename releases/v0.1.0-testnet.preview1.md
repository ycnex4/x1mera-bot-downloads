# X1MERA Bot 0.1.0 — Testnet Preview 1

First Windows x64 installer preview. The required runtime is bundled; users do not need to install Python, WSL or Node.js.

## Included

- Create or reopen a separate local executor wallet.
- Protect executor key storage using Windows DPAPI and user-only file permissions.
- Inspect a job using public owner and executor addresses.
- Show funding balances, the next planned step and stop reasons.
- Local transaction-journal foundation for later execution support.

## Current limits

- **X1 Testnet only.**
- **Transaction signing and sending are disabled.**
- No automatic connection/pairing with the website.
- The website button currently opens `http://localhost:3000/jobs` for this test stage.
- No automatic updates, wallet export/recovery or computer migration.
- The installer is unsigned.
- Manual desktop use, upgrade/uninstall profile preservation and power-loss checks are not yet complete.

Seven native Windows storage tests passed without skips on a hosted Windows runner. Both the portable executable and the installed executable passed offline self-checks, including bundled runtime, wallet/journal reopen and Tk initialization. These checks used isolated temporary test data, not user wallets or blockchain transactions.
